Tech Stack

🤖 LLM Google Gemini

Gemini 2.0 Flash for fast, high-quality language generation with multi-turn conversation history.

🔍 Search Google CSE

Google Custom Search Engine retrieves real-time web results to ground answers in current information.

📐 Embeddings HuggingFace

sentence-transformers/all-MiniLM-L6-v2 encodes queries and documents into 384-dim dense vectors.

🗄️ RAG Pipeline In-Memory

Retrieved snippets are embedded and stored in a vector store. Cosine similarity retrieves the top-k relevant chunks, which are injected into the Gemini prompt as context.

⚡ Backend FastAPI

Async FastAPI server with CORS, Pydantic validation, and a clean REST API. Production-ready with Uvicorn.

🎨 Frontend Vanilla JS

Pure HTML/CSS/JS with Marked.js for markdown rendering, Highlight.js for code, and smooth animations.
